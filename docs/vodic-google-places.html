03

Uključite Places API i napravite ključ≈ 5 MINUTA

Uključivanje API-ja

Najsigurnije je preskočiti pretraživanje i otići izravno na stranicu servisa:

https://console.cloud.google.com/apis/library/places.googleapis.com

Provjerite da je gore odabran pravi projekt, pa kliknite Enable. Alternativno: APIs & Services → Library i upišite Places API (New).

Dva API-ja gotovo istog imena

Naziv u sučeljuNaziv servisaTreba li vam
Places API (New)places.googleapis.comDa — agent poziva places.googleapis.com/v1/…
Places APIplaces-backend.googleapis.comNe — stara inačica

Naziv servisa je pouzdaniji od naziva u sučelju jer ga Google mijenja rjeđe. Vidjet ćete ga i u svakoj poruci o grešci, u polju metadata.service.

Izrada ključa

  1. APIs & Services → Credentials.
  2. Create credentials → API key.
  3. Google prikaže ključ u skočnom prozoru. Kopirajte ga odmah — počinje s AIza i ima oko 39 znakova.
  4. Kliknite Edit API key i odmah ga ograničite (sljedeći odjeljak).

Ograničavanje ključa

Neograničen ključ može svatko tko ga vidi koristiti na vaš trošak. Google izrijekom preporučuje ograničavanje.

PostavkaŠto odabratiZašto
API restrictionsRestrict key → označite samo Places API (New)Ključ tada ne može pozvati nijednu drugu Googleovu uslugu, pa i ako procuri, šteta je ograničena na ovaj jedan API
Application restrictionsZa pokretanje na vlastitom računalu: IP addresses i vaša javna adresa.

Ako u popisu „Restrict key“ nema Places API (New)

To nije kvar nego posljedica redoslijeda: popis prikazuje samo API-je koji su već uključeni u tom projektu. Ako se stavka ne pojavljuje, API još nije uključen — ili je uključen u drugom projektu.

Redom:

  1. Provjerite je li gore u traci odabran isti projekt u kojem radite ključ.
  2. Otvorite https://console.cloud.google.com/apis/library/places.googleapis.com i kliknite Enable. Ako piše Manage umjesto Enable, već je uključen.
  3. Provjerite popis uključenih: APIs & Services → Enabled APIs & services. Ondje mora stajati Places API (New).
  4. Vratite se na Credentials i osvježite stranicu (Ctrl+F5). Popis se puni pri učitavanju, pa novo uključeni API ne vidite bez ponovnog učitavanja. Googleu zna trebati minuta-dvije.

Alternativa preko naredbenog retka, ako imate gcloud:

gcloud services enable places.googleapis.com --project=ID-VAŠEG-PROJEKTA
gcloud services list --enabled --project=ID-VAŠEG-PROJEKTA | grep places

Ako ni nakon toga ne uspijete: privremeno ostavite Don't restrict key, pokrenite provjeru iz koraka 4 da potvrdite da sve ostalo radi, pa se vratite na ograničavanje. Neograničen ključ ne držite dulje nego što morate i nikako ga ne stavljajte u repozitorij.

Ako ostavljate „None“: ključ je zaštićen samo ograničenjem na Places API i tajnošću. Zato nikada ne ide u kôd ni u commit, nego isključivo u GitHub Secrets (korak 5). Repozitorij već ima .env u .gitignore.

04

Provjerite ključ prije nego potroši kvotu≈ 2 MINUTE

Ne pokrećite odmah otkrivanje objekata. Prvo pokrenite provjeru — troši dva poziva i točno vam kaže što ne valja ako nešto ne valja.

Put A — kroz GitHub, bez ijedne naredbe PREPORUČENO

Ne treba vam ni terminal, ni Node, ni kopija repozitorija na računalu. Sve se izvodi na GitHubovim poslužiteljima.

Preduvjet: grana mora biti spojena u main

GitHub prikazuje gumb Run workflow samo za workflowe koji postoje na glavnoj grani. Njihova dokumentacija to kaže izrijekom: „This event will only trigger a workflow run if the workflow file exists on the default branch.“ Dok je posao samo na grani claude/brave-wozniak-so9hwt, gumba nema.

Zato prvo otvorite Pull request s te grane u main i spojite ga. Time se aktivira i tjedni raspored — što je ionako cilj, a bez ključa se sloj ocjena jednostavno preskače, pa spajanje ništa ne kvari.

  1. Spremite ključ kao tajnu. U repozitoriju: Settings → Secrets and variables → Actions → New repository secret.
    Name: GOOGLE_MAPS_API_KEY  ·  Secret: vaš ključ  ·  Add secret.
  2. Pokrenite provjeru. Kartica Actions → u popisu lijevo odaberite „Otkrij objekte (Google Places) — ručno“ → gumb Run workflow.
    Grana: claude/brave-wozniak-so9hwt  ·  Što napraviti: samo-provjeri-kljuc → Run workflow.
  3. Pogledajte rezultat. Kliknite na pokrenuti posao pa na korak „Provjeri ključ“. Ondje piše isto što bi pisalo u terminalu — tri kvačice ili točna uputa što popraviti.

Kad provjera prođe, pokrenite isti workflow ponovno, ovaj put s izborom provjeri-i-otkrij-objekte. On izgradi registar, ispiše sažetak s brojem objekata i procjenom kvote, i sam ga commita u repozitorij. Time je korak 5 gotov i preskačete ga.

Put B — lokalno, u terminalu

Samo ako želite raditi na vlastitom računalu. Treba vam git i Node.js 20 ili noviji.

Najvažnije: prvo morate preuzeti repozitorij i ući u njegovu mapu. Naredbe se ne izvode bilo gdje — ako ih pokrenete u pogrešnoj mapi, git javlja fatal: not a git repository, a npm install instalira pakete nekog drugog projekta.

Ako je repozitorij privatan, git clone će tražiti prijavu. Najjednostavnije je instalirati GitHub CLI pa gh auth login i gh repo clone Salas-Hrastik/visitlogic-mvp. Ako vam to zapinje, upotrijebite Put A — ne gubi se ništa.

Ovaj korak pokrećete samo jednom. Traži objekte u Slavonskom Brodu i sprema njihove place_id oznake. Google dopušta trajno čuvanje place_id-a, pa se otkrivanje ne mora ponavljati.

Nakon uspješnog izvođenja workflow sam commita osvježene podatke i izvještaj, a datoteke prilaže i kao artefakt koji možete preuzeti iz sučelja GitHub Actions.

08

Što nakon prvog tjednaTRAJNO

Sloj ocjena rješava prazne kategorije, ali ne rješava sve. Redoslijed sljedećih koraka po omjeru koristi i truda:

  1. Google Business Profile API za objekte koji sami daju pristup. Jedini put do svih recenzija jednog objekta i jedini kod kojeg smijete pohraniti tekst. Places vraća najviše pet recenzija po pozivu.
  2. Vlastita anketa s QR kodom u turističkom uredu, na Tvrđavi i na događanjima. Pravno najčišći izvor i jedini koji pokriva posjetitelje koji ništa ne objave — a to je velika većina.
  3. Registar objekata kao geo-filtar. Kad postoji, zamjenjuje pravilo koje je u prvoj iteraciji davalo preciznost 0,50 i podiže je iznad 0,90.
  4. Model za hrvatski sentiment umjesto leksičkog MVP-a. Tek kad prva tri koraka daju dovoljan uzorak za podešavanje.

Dvije stvari koje se ne rade

Struganje Google Mapsa protivno je uvjetima korištenja i neće biti implementirano. Pohrana ocjena i teksta recenzija na disk također — zato agent zapisuje samo izvedene agregate. Iznimka je Business Profile, gdje objekt sam daje pristup svojim podacima.
